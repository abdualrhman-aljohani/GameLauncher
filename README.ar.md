# GameLauncher

**[English](README.md) | العربية**

مُشغّل ألعاب خفيف مبني بتقنية Win32 النيتف — تضغط اختصار من أي مكان بويندوز، تختار لعبتك من دائرة تفاعلية على الشاشة، وتشتغل على طول. بدون ما تدور عليها بسطح المكتب، وبدون ما تفتح مكتبة لعبة منفصلة أول.

## ليش هذا المشروع؟

ألعابك موزّعة بين سطح المكتب، Steam، متجر مايكروسوفت، ومجلدات متفرقة. GameLauncher يجمعها كلها ببعد ضغطة زر وحدة، بغض النظر عن أي شي شغال عندك حالياً — حتى لو انت داخل لعبة ثانية.

## الميزات

- **دائرة ألعاب تفاعلية** — قائمة دائرية متحركة على الشاشة مع **13 ثيم قابل للتخصيص** (Neon، Glass، Sakura، Vortex، وغيرها)
- **دعم شامل لكل مصادر الألعاب** — ملفات `.exe`، اختصارات `.lnk`، روابط بروتوكول (URL)، تطبيقات متجر مايكروسوفت (UWP)، ألعاب Steam، ومحاكيات Google Play Games
- **كتم صوت ذكي لكل لعبة** — يكتم تلقائياً باقي التطبيقات (Discord، المتصفح، إلخ) وانت تلعب، مع اختصار مخصص لكتم/فك كتم أي تطبيق نشط فوراً
- **تحكم بالأداء** — تحدد أولوية المعالج (Priority) وأي أنوية CPU تستخدمها كل لعبة (Affinity)
- **دعم يد تحكم Xbox** — تفتح وتتنقل وتغلق الدائرة بيد التحكم بالكامل
- **إحصائيات لعب مفصلة** — عدد مرات التشغيل، إجمالي وقت اللعب، وتاريخ آخر مرة لعبت فيها كل لعبة
- **تبديل لغة الكيبورد تلقائياً** — تربط لغة معينة (عربي/إنجليزي) بكل لعبة تتفعل تلقائي وقت تشغيلها
- **نسخ احتياطي واسترجاع** — تصدير واستيراد كل قائمة ألعابك وإعداداتك بضغطة وحدة

## بُني باستخدام

**C++ / Win32** نيتف بالكامل — بدون .NET أو Electron. لوحة التحكم مبنية بـ **WebView2** عشان تطلع بشكل عصري مع الحفاظ على خفة البرنامج بالذاكرة والمعالج.

## المتطلبات

- ويندوز 10 (إصدار 1809 فأعلى) أو ويندوز 11
- [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/) (مثبت مسبقاً بويندوز 11 وأغلب تحديثات ويندوز 10)

## البداية

1. شغّل `GameLauncher.exe` ← يختفي بشريط المهام (Tray)
2. اضغط `Ctrl+Alt+G` لفتح دائرة الألعاب
3. من أيقونة الـ Tray ← **"لوحة التحكم..."** لإضافة وإدارة ألعابك

## الاختصارات

| الاختصار | الوظيفة |
|---|---|
| `Ctrl+Alt+G` | فتح دائرة الألعاب |
| `Ctrl+Alt+M` | كتم/إلغاء كتم التطبيق النشط حالياً |

الاختصاران قابلان للتخصيص بالكامل من لوحة التحكم.

## البيانات

كل إعداداتك وقائمة ألعابك تُحفظ محلياً على جهازك في:
```
%APPDATA%\GameLauncher\
```
بدون سحابة، بدون تتبع، بدون حسابات.

## البناء من الكود المصدري

يتطلب Visual Studio 2022 مع حزمة **Desktop development with C++**.

```
git clone https://github.com/abdualrhman-aljohani/GameLauncher.git
cd GameLauncher
```

افتح `GameLauncher.sln`، اختر الإعدادات المناسبة، وابنِ المشروع.
