## 🎯 عن المشروع

GameLauncher هو مُشغّل ألعاب خفيف لويندوز، مبني بالكامل بلغة **C++ نيتف**، وفكرته الأساسية بسيطة: **توصل لأي لعبة من ألعابك بأي وقت وبأي مكان بضغطة زر وحدة، بدون ما تدور عليها بسطح المكتب أو تفتح مكتبات منفصلة** زي Steam أو متجر مايكروسوفت أو Epic.

تضغط اختصار وحدة، وتطلع لك دائرة تفاعلية متحركة فوق أي شي تسويه — حتى لو كنت داخل لعبة ثانية. تضغط أيقونة اللعبة اللي تبيها وتشتغل على طول. وفيه لوحة تحكم منفصلة تدير منها مكتبتك وثيماتك وإعداداتك بواجهة رسومية عصرية، بالإضافة لميزة اختيارية اسمها **Performance Black Box** تعطيك مراقبة احترافية للـ FPS والمعالج وكرت الشاشة بدون ما تلمس اللعبة نفسها أبداً.

المشروع مبني بالكامل بـ **C++ / Win32** نيتف — بدون .NET أو Electron — عشان يضل خفيف جداً على الذاكرة والمعالج، مع لوحة تحكم مبنية بـ WebView2 عشان تطلع بشكل عصري بدون ما تضحي بهالخفة. كل ميزات المراقبة تعتمد حصراً على واجهات ويندوز الرسمية الموقّعة من مايكروسوفت، فيضل استخدامه آمن حتى بالألعاب المحمية بأنظمة Anti-Cheat.

**باختصار:** اختصار وحدة، دائرة وحدة، ووصول فوري لكل مكتبة ألعابك — مع رؤية احترافية اختيارية لأداء جهازك، بدون أي تعديل أو حقن أو قراءة لملفات أو ذاكرة اللعبة.

## ✨ المميزات

### 🎯 دائرة الألعاب

- **اختصار قابل للتخصيص** — الافتراضي `Ctrl+Alt+G`
- **دعم Xbox Controller** — افتح الدائرة بزر من يد التحكم
- **Quick Slots 1-9** — افتح لعبتك المفضلة بضغطة رقم
- **أيقونات صافية** — إخفاء كامل للإطارات والهالات
- **دعم كامل** — `exe`, `lnk`, `url`, `UWP`, `Steam`

### 🎛️ لوحة التحكم

- واجهة **WebView2** حديثة
- **خلفيات مخصصة** للوحة ولدائرة الألعاب
- **مظهر زجاجي (Acrylic)** حقيقي
- **سحب وإفلات** الملفات والمجلدات
- **نسخ احتياطي** واستيراد بصيغة JSON
- **إعادة تشغيل كمسؤول** بزر واحد

### 📊 Performance Black Box

- **FPS + Frame Time** عبر ETW/DXGI
- **GPU Temp / Power / Usage / VRAM** عبر NVML
- **CPU Usage + RAM**
- **Stutter Detection** تلقائي
- **1% Low / 0.1% Low** FPS
- **رسوم بيانية تفاعلية**
- **تصدير CSV** لكل جلسة
- حد **30 جلسة** لكل لعبة

### 🔇 كتم الصوت الذكي

- **Ctrl+Alt+M** لكتم التطبيق النشط فوراً
- **Core Audio API** الرسمي بدون Hooks
- قائمة التطبيقات المكتومة
- **إلغاء كتم الكل** بزر واحد

### 🎮 Overlay مباشر

- **Ctrl+Shift+O** لإظهار/إخفاء
- FPS + GPU + CPU + RAM + وقت اللعب
- **يتحدّث كل 500ms**
- شفافية قابلة للتخصيص
- يظهر تلقائياً عند تشغيل لعبة (اختياري)

## 🛡️ السلامة أولاً

GameLauncher مبني على مبدأ **"لا تلمس اللعبة"**.

**ممنوع تماماً:**

- حقن DLL
- قراءة ذاكرة اللعبة
- Hooks على DirectX / OpenGL / Vulkan
- تعديل ملفات اللعبة
- تعديل اتصالات الشبكة
- Overlay Injection

**مسموح — واجهات ويندوز الرسمية فقط:**

- ETW (Event Tracing for Windows)
- NVML (NVIDIA Management Library)
- Core Audio API
- D3DKMT
- PDH
- GDI+

### 🎯 متوافق مع Anti-Cheat؟

- **بدون Black Box** — آمن 100% في جميع الألعاب التنافسية
- **مع Black Box** — آمن نظرياً لأن كل الواجهات موقّعة من Microsoft

## 📦 المتطلبات

**إلزامي:**

- Windows 10 (2004+) أو Windows 11
- WebView2 Runtime — مثبّت مسبقاً على Windows 11
- معالج x64

**للبناء من المصدر:**

- Visual Studio 2022 مع `Desktop development with C++`
- NuGet Package Manager

**اختياري:**

- صلاحيات Admin — مطلوبة فقط لـ ETW FPS على ويندوز أقدم من 10 2004
- NVML — مطلوبة فقط لقراءة حرارة GPU

## 📖 الاستخدام السريع

**1)** شغّل `GameLauncher.exe` — يعمل في الـ System Tray.

**2)** افتح دائرة الألعاب بـ `Ctrl+Alt+G` أو بالنقر المزدوج على أيقونة الـ Tray.

**3)** اضغط زر **Hub** في الوسط لفتح لوحة التحكم.

**4)** أضف ألعابك — سحب وإفلات، أو زر "إضافة لعبة".

**5)** فعّل **Black Box** من تبويب تفاصيل أي لعبة لمراقبة أدائها.

## 🐛 حل المشاكل

### FPS لا يعمل؟

- شغّل GameLauncher **كمسؤول**
- أو تأكد من Windows 10 2004+

### حرارة CPU لا تظهر؟

- ميزة مؤجلة — تنتظر دعم PawnIO
- البديل — استخدم HWiNFO بالتوازي

### اللوحة لا تُفتح؟

- تأكد من تثبيت **WebView2 Runtime**

### الاختصارات لا تعمل؟

- قد تكون محجوزة من برنامج آخر
- غيّرها من الإعدادات
